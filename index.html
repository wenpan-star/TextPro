📖 显示/隐藏 帮助说明
正则表达式语法： 支持 JavaScript 正则，如 \d 匹配数字，\s 空白符，捕获组用 $1 $2 引用。替换文本里写 \$ 表示字面美元符号（避免被解释为捕获组）。
JS 模式： 函数体接收参数 result (匹配的完整字符串)，返回替换后的字符串。示例：return result.toUpperCase();
@js: 前缀： 在替换文本开头加 @js: 会自动启用 JS 模式；如需输出字面 "@js:"，使用 @@js: 转义。
安全警告： JS模式可能执行任意代码，切勿使用不可信规则。本工具已拦截危险API（fetch, eval, document, self, Reflect, WebAssembly 等），并对字符串拼接绕过做了预折叠检测。
JS 信任模型（按规则）： 每条规则首次启用 JS 模式时会弹出确认；同意后该规则在本设备上不再重复询问。可通过顶部 🔓 指示器一键撤销全部规则信任。JS 模式全部在后台计算线程运行，即使出现死循环也不会卡死页面。
快速替换： 临时执行一条规则，不保存到规则表，方便测试。点击"存为规则"可固化到主表。
迭代式净化： 批量运行后如不满意，点击"📋 结果→源"即可在上次结果基础上继续处理。
核心概念： 本工具区分三个概念 —— 默认规则 是置顶的特殊预设（不可删除，可编辑、可重命名），命名预设 是用户创建的普通预设，当前工作区 是 activePresetId 指向的那个预设（可以是默认规则或任意命名预设）。
我的预设（编辑方式）： 打开"我的预设"面板可以看到所有预设，包括顶部的"📋 默认规则"。编辑任意预设的规则不会影响其他预设，每个预设的内容独立存储。若编辑的预设正是当前工作区，主表会同步更新。
主表↔预设自动同步： 当当前工作区是命名预设时，编辑主表规则后会自动同步回预设（防抖 400ms）。无需手动点击"保存回预设"（该按钮保留用于强制立即同步）。存在未同步的修改时，关闭页面会弹出离开确认。
加载此预设： 把一个命名预设设为当前工作区。当前工作区将被替换为该预设的规则内容。如果当前工作区有未保存的修改，会弹确认框。
切换回默认规则： 把当前工作区从命名预设切换为默认规则。仅当当前工作区是命名预设时此按钮才可见。
编辑默认规则： 在"我的预设"面板选中"默认规则"后，可以像编辑普通预设一样增删改规则。重命名默认规则需要二次确认。
→追加： 预设中的每条规则卡片有"→追加"按钮。点击后弹出目标选择器，可将该规则追加到默认规则或任意其他预设。
存在性徽章： 规则卡片底部显示"存在于：📋 默认规则 · ⭐ 其他 N 处"。点击可展开查看具体哪些预设中存在。
搜索预设： 预设搜索框支持搜索预设名和规则内容。搜索框右侧按钮可切换"字段范围（🔍/🏷️）"与"数据源范围（🌐/🏷️）"。在过滤视图下，上移/下移按钮按可见列表的相对顺序移动。
重复项提示： 主表若出现内容相同的规则，规则名称旁会显示 ⚠️ 徽章"与 #N 重复"。
大文本处理： 支持最大 20MB 文本。超过 1MB 时自动使用后台计算线程处理，界面保持流畅，可实时查看进度，可随时点击"✕ 取消"终止。
状态持久化： 所有设置与界面状态会在下次打开时自动恢复（前提是"🔄 启动时自动恢复上次状态"保持开启）。
持久化存储权限： 为提高数据存活率，本工具会在您首次与页面交互时申请"持久化存储"权限。若浏览器拒绝，顶部会显示提示条，建议收藏本页面或使用"导出设置"备份。
导入导出： 完整配置包含文本内容、默认规则、预设库、界面布局、当前工作区等状态，跨设备可用。导入时默认采用"合并"策略，同名项以文件为准，新项追加。
快捷键： Ctrl+S 立即保存；Ctrl+Shift+D 切换暗色模式。
