# TextPro 文本净化工具

> 🧹 一款纯前端的文本批量净化工具，支持正则表达式、JS 模式、规则表批量运行、命名预设管理、完整 UI 状态持久化。

---

## ✨ 功能特性

### 文本处理

- **正则表达式替换**：支持 JavaScript 正则语法，捕获组 `$1` `$2` 反向引用
- **JS 模式**：替换文本作为函数体，参数 `result` 为匹配字符串，返回值为替换结果
- **循环执行直到稳定**：单条规则可反复执行直到文本不再变化（防止嵌套场景遗漏）
- **快速替换**：临时执行一条规则，不写入规则表，方便测试
- **快速替换存为规则**：试出好规则可一键固化为规则表项，无需手动抄写
- **`\$` 转义**：替换文本里写 `\$` 表达字面美元符号，避免被解释为捕获组

### 结果区流转（迭代式净化）

- **📋 结果→源**：把结果作为新的源文本，清空结果区 —— 支持"处理 → 不满意 → 调整 → 再处理"的迭代工作流
- **🔁 交换**：源文本与结果文本互换
- **↻ 重置**：清空结果区

### 规则表

- **顺序批量运行**：按 order 顺序依次应用所有勾选规则
- **分帧执行**：每执行 3 条规则让出一次主线程，长文本下 UI 不假死
- **运行进度显示**：运行期间显示 `正在运行 N/M · 规则名`，百分比实时更新
- **错误汇总条**：批量运行出错时展开可折叠的错误列表，支持定位与复制
- **上移 / 下移 / 置顶 / 置底**：可视化调整执行顺序
- **独立 JS 模式**：每条规则可单独启用 JS 模式，启用前有安全确认（**按规则信任**，详见"安全"章节）
- **可拖拽列宽**：鼠标拖动表头右侧边缘调整列宽，配置持久化
- **预定义模板**：内置常用规则（清除 HTML 标签、删除手机号、删除邮箱等）
- **待运行数量提示**：批量运行按钮显示 `(N/M)`，让用户知道会执行多少条
- **增量渲染**：编辑单元格后只更新对应 DOM，焦点、事件监听器全部保留
- **批量运行取消**：大文本运行期间可点击"✕ 取消"按钮终止
- **列宽 reflow 优化**：签名缓存避免无意义的样式重写
- **重复项徽章紧凑显示**：单一大重复组时，徽章只显示前 3 个 order + "等 N 条"
- **重复检测缓存**：按规则内容签名缓存检测结果，编辑名称等字段不会触发重算

### 命名预设管理

- **默认规则（置顶特殊预设）**：所有预设置顶显示的第一个就是"默认规则"
  - 与命名预设**完全平级**，可以编辑规则、重命名、清空
  - 不可删除预设本身（必须有一个"默认"）
  - 可以改成任意名字（需二次确认）
- **保存为命名预设**：将当前工作区保存为一套命名配置
- **多预设管理**：可创建、重命名、删除、另存为多套预设
- **搜索过滤**：预设名称 + 规则内容实时搜索，快速定位
- **二维搜索模型**：
  - 字段范围按钮（🔍/🏷️）：搜索"预设名 + 规则内容" 或 "仅预设名"
  - 数据源范围按钮（🌐/🏷️）：搜索"全部预设" 或 "仅当前选中项"
- **预设内独立编辑**：每个预设含独立的规则列表，可增删改、排序
- **卡片式规则列表**：预设内的规则以三行卡片形式展示（无需横向滚动）
- **单条规则追加**：每条预设规则卡片有 `→追加` 按钮，可选择追加到默认规则或其他预设
- **加载为当前工作区**：将预设加载为当前工作区，加载前有覆盖确认（若有未保存修改）
- **放大显示**：模态框支持放大到接近视口大小（点击标题栏的 ⛶ 按钮）
- **悬停提示浮层**：标题栏 `❓` 按钮悬停或点击显示使用提示
- **随配置导出/导入**：预设随设置文件一同流转，支持覆盖 / 追加 / 合并三种合并策略
- **键盘无障碍**：Tab 聚焦、↑↓ 导航、Enter/Space 选择
- **焦点返还**：关闭模态框后焦点还给触发按钮（WAI-ARIA 标准）
- **预设列表增量渲染**：搜索或刷新时只更新变化的项，DOM 节点尽可能复用
- **过滤缓存**：预设过滤结果按"查询词 + 字段范围 + 数据源 + 预设库引用"缓存，避免每次渲染都全量遍历
- **过滤视图排序**：搜索过滤下，上移/下移按"当前可见列表"的相对位置移动，符合视觉预期
- **主表↔预设自动同步**：当当前工作区是命名预设时，编辑主表规则后**自动同步回预设**（防抖 400ms），无需手动点击"保存回预设"

### 核心概念（本版本明确区分）

- **默认规则** = 一个置顶的特殊预设，与命名预设完全平级。可编辑、可重命名、不可删除。独立存储于 `AppState.defaultRules`。
- **命名预设** = 用户创建的普通预设，存储于 `AppState.presets`。
- **当前工作区** = `activePresetId` 指向的那个预设。可以是默认规则（默认情况），也可以是任意命名预设。
- **主表** = 编辑区，显示的是**当前工作区的内容副本**，存储于 `AppState.customRules`。
- **保存回预设** = 把主表当前内容保存到当前工作区对应的预设。
- **编辑主表** = 只改 `customRules`；当工作区是命名预设时会自动同步回预设。
- **编辑活动预设** = 编辑的预设恰好是当前工作区时，`preset.rules` 与 `customRules` 双向同步，两边始终保持一致。

### 界面与持久化

- **完整 UI 状态持久化**：下次打开自动恢复上次编辑状态与所有设置
- **AES-GCM 加密**：所有持久化数据加密后存入 IndexedDB
- **明文备份**：主题 / 文件名 / 同步模式 / autoLoadSnapshot 在 localStorage 中明文备份
- **暗色模式**：一键切换，切换即持久化
- **同步滚动**：比例同步 / 像素同步 / 关闭三种模式
- **配置导出 / 导入**：JSON 格式，支持覆盖 / 追加 / 合并三种策略
- **导入模式选择对话框**：导入时若有同名项，单个对话框提供三选项，**默认选中"合并"**（安全性优先）
- **启动时自动加载快照**：可关闭，关闭后下次打开从空文本开始
- **IndexedDB 打开超时保护**：多标签页 blocked 时 15 秒超时降级，避免白屏
- **IndexedDB 连接复用**：模块级缓存连接，避免每次操作都 open/close
- **持久化存储权限申请（延后）**：首次用户交互后自动申请 `navigator.storage.persist()`，提高数据存活率
- **时间戳钳制**：导入配置时把 createdAt / updatedAt 钳制到合理范围，防止未来时间扰乱排序
- **离开确认（beforeunload）**：存在未同步修改时，关闭页面会弹出浏览器原生离开确认

### 安全

- **JS 模式四阶防御**：
  - 危险 API 黑名单（fetch / eval / document / self / Reflect / WebAssembly 等）
  - 字符串拼接折叠检测（`'win'+'dow'` 或 `` `win`+`dow` `` 折叠后再匹配）
  - 方括号访问检测（`self['document']` / `['cookie']` 等字面量精确匹配）
  - 原型链属性访问检测（`.constructor` / `.__proto__`）
- **按规则信任模型（默认）**：
  - 每条规则首次启用 JS 模式时弹出确认；同意后该规则在本设备上不再重复询问
  - 信任集合镜像到 localStorage，跨会话保留
  - 可通过顶部 🔓 指示器一键撤销全部规则信任
  - 若 `CONFIG.JS_TRUST_RULE_BASED = false`，则退回旧的"会话级信任"模型
- **JS 模式强制走 Worker**：即使小文本也走后台计算线程，统一受 60 秒超时保护，避免死循环卡死主线程
- **大文本保护**：超过 2MB 提示，超过 20MB 拒绝处理
- **应用预设前的覆盖确认**：避免误操作丢失当前工作区
- **解密失败保护**：密钥不匹配时弹窗询问；与"JSON 解析失败"分开处理，避免误判
- **存储状态透明化**：IndexedDB 不可用时顶部常驻警告横幅
- **原型污染防御**：所有外部导入的规则 / 预设对象都经过安全拷贝

### 交互优化

- **预设管理器打开时禁用全局快捷键**：避免与内部交互冲突
- **统计对话框打开时禁用全局快捷键**：同样避免冲突
- **搜索无重叠匹配**：与浏览器 Ctrl+F 语义一致
- **搜索结果用于替换**：搜索计数旁 `⤴ 用于替换` 按钮
- **搜索不抢选区**：输入搜索词时不再改变结果区选区
- **Enter 立即导航**：flush 掉输入防抖，保证用最新搜索词导航
- **搜索上限警告抑制**：达到上限的提示在 5 秒窗口内不重复弹出
- **结果区输入搜索防抖**：手动编辑结果区时，搜索延迟 300ms 触发，避免每次按键都卡顿
- **同步滚动 rAF 节流**：触摸板惯性滚动下合帧处理，避免另一侧 textarea 频繁重排
- **工具栏分组**：编辑 / 库 / 文件 / 危险操作分组，加分隔线
- **破坏性操作视觉隔离**：`↻ 恢复出厂` 用 danger 配色
- **预设模态框空状态引导**：空状态下显示"从当前表创建"主按钮
- **模态框 Esc 键正确处理**：追加目标模态框 / 悬停浮层 / 统计对话框打开时，按 Esc 只关闭栈顶
- **统计对话框支持一键复制**：方便用户粘贴到笔记
- **追加防抖提示**：2 秒内重复点击同一目标会明确提示"请勿重复点击"
- **Toast 堆叠限制**：最多同时显示 4 个 toast，超出时淘汰最旧的
- **批量运行取消无二次确认**：取消本身是安全操作
- **错误边界降级 UI**：启动失败时显示专用降级卡（含"重新加载"按钮和错误详情）
- **noscript 降级提示**：禁用 JS 时显示居中提示卡，说明需要启用 JavaScript

### 快捷键

- **Ctrl+S**：立即保存（与文本编辑器习惯一致）
- **Ctrl+Shift+D**：切换暗色模式（**不再劫持** Ctrl+D 的浏览器"添加书签"）

### 性能优化

- **增量渲染**：编辑单元格时只更新对应行，不重建整表
- **重复检测缓存**：内容签名相同则复用结果
- **存在性索引增量更新**：编辑单条规则时只更新该条在索引里的位置，不全量重建
- **lower-case 缓存惰性失效**：编辑结果区不直接清空 20MB 文本的 toLowerCase 缓存
- **保存并发保护**：保存进行中时标记 pending retry，避免旧数据覆盖新数据
- **列宽应用签名缓存**：避免无意义的 reflow
- **scrollTop rAF 恢复**：预设列表、详情滚动位置延迟一帧恢复，避免被钳制
- **预设过滤缓存**：按查询参数 4 元组缓存，避免每次渲染都全量遍历
- **无副本滚动定位**：大文本搜索后滚动定位，直接在原字符串上遍历换行符，不生成副本
- **Worker 进度节流**：批量运行进度消息按 100ms 节流，最后一条必然上报

## 🚀 运行方式

### ⚠️ 重要：不能用 `file://` 直接打开

本项目使用 **ES Module**，浏览器出于 CORS 安全策略禁止 `file://` 协议加载模块。**必须通过 HTTP/HTTPS 访问**。

### 方式一：Python（推荐）

```bash
cd /path/to/TextPro
python -m http.server 8000
```

然后访问 `http://localhost:8000`

### 方式二：Node.js

```bash
npx http-server -p 8000
```

### 方式三：VS Code Live Server

安装 Live Server 扩展 → 右键 `index.html` → Open with Live Server

## 📖 使用指南

### 快速上手

1. 通过 HTTP 访问 `index.html`
2. 在"源文本"区粘贴文本
3. 编辑或导入规则表
4. 点击"⚡ 批量运行"查看结果
5. 结果不满意时，点击"📋 结果→源"迭代处理

### 命名预设工作流

1. 点击"⭐ 我的预设"打开预设管理器
2. 点击"📋 从当前工作区创建"保存当前规则表为一套预设
3. 加载预设到工作区后，编辑主表会自动同步回预设（防抖 400ms）
4. 或点击"💾 保存回预设"强制立即同步

### 安全建议

- JS 模式仅在完全信任规则来源时启用
- 定期使用"📤 导出设置"备份配置
- 若顶部显示"存储持久化权限未获得"，建议收藏本页面或安装为 PWA

## 🔧 技术栈

- **纯静态前端**，无需构建步骤
- **ES Module** 原生模块化
- **Web Crypto API** AES-GCM 加密
- **IndexedDB** 持久化存储
- **Web Worker** 大文本计算线程
- **CSS 变量 + 类切换** 主题系统
